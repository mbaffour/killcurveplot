Draft CHANGELOG bullets for v2.22 (stats engine only; the supervisor folds these into CHANGELOG.md).

- New statistics engine, a pure-function block `v2.22 stats engine` in `Lysis_Curve_App_v28.R` (no UI, no server code, no change to existing functions or defaults). Documented in `docs/STATISTICS_REFERENCE.md`, tested by `tests/test_v222_stats.R`.
- Column statistics: `describe_column()` / `describe_metrics()` (n, mean, SD, SEM, CV %, t-based CI, median, quartiles, IQR, range, bias-corrected skewness and excess kurtosis as in Prism, geometric mean, Shapiro p); `normality_table()` (per sample and pooled residuals) and `qq_frame()` for Q-Q plots; `variance_check()` (Brown-Forsythe and Bartlett).
- Grouped tests: `omnibus_table()` (one-way ANOVA with eta squared, Welch ANOVA, Kruskal-Wallis with epsilon squared) and `posthoc_table()` with Tukey, Holm-adjusted Welch t, Games-Howell, Dunn (tie-corrected, Holm or Bonferroni), Dunnett, Bonferroni and Sidak. Dunnett uses the multivariate-t integral when `mvtnorm` is installed and otherwise falls back to Holm-adjusted Welch t against the reference, stated in the `method` column.
- Time courses: `two_way_time_anova()` (sample x time, wells as repeated-measures subject: `nlme::lme` with AR(1) errors, else `aov` with an `Error(well)` stratum, else plain two-way `aov`; log readings by default) and `per_time_comparisons()` (each sample vs the reference at every time point, Welch t, Sidak / Holm / Bonferroni across time points).
- Outliers: `outlier_tests()` (Grubbs, MAD, IQR fences; `grubbs_p()` / `grubbs_critical()` verified against the published table) and `replicate_outlier_flags()` (replicate curves against the per-sample median curve). Nothing is ever removed automatically.
- Area under the curve: `auc_table()` (per-replicate trapezoid AUC above a baseline over a time window, exact at baseline crossings, per-sample mean / SD / SEM / CI, relative AUC with a log-delta CI) and `auc_compare()`.
- Small tools: `one_sample_tests()` (t and Wilcoxon signed-rank), `correlation_table()` (Pearson / Spearman with CI), `linear_fit_table()` and `linear_band()` for the metric explorer, `error_half_width_extra()` (range, IQR, 90 % and 99 % CI as asymmetric offsets around the mean), `stats_method_sentence()` for editable methods text and the `STATS_V222_DEFINITIONS` table.
- Honest at n = 3: every table has a `note` column that warns about low power (Shapiro and variance tests, rank-test attainable p-values, outlier rules); bad input (n = 1, constant values, NA, unknown reference) returns NA rows with a note instead of an error.
- `rstatix`, `car`, `nlme` and `mvtnorm` are optional: the app still sources and every function runs without them (documented fallbacks); `rstatix` and `car` are used only as cross-checks in the tests.
